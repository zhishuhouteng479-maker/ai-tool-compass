# 新規商材（アフィリエイト）発掘リスト

Ghost-Rainmakerからのリサーチ報告です。
当サイト「AI Tool Compass」の収益をさらに最大化するために、社長にA8.net等のASPで検索・取得してきていただきたい「有望な商材カテゴリ・キーワード」をリストアップしました。

以下のキーワードで検索し、良さそうな案件（即時提携できるものや報酬単価が高いもの）があれば、リンクを取得して `affiliate_candidates.md` へ追記をお願いします。

---

## 🔍 A8.netで検索していただきたいキーワード

### 1. 「ノーコード」「Web制作」
*   **狙い:** AIを使ったサイト構築記事の着地点として非常に相性が良いです。
*   **具体例:** ペライチ、STUDIO、Shopify、BASE などのWeb制作ツール。

### 2. 「プロジェクト管理」「タスク管理」ヒット数ゼロ
*   **狙い:** B2B向けの業務効率化記事に必須のジャンルです。法人の導入が決まれば高額報酬が狙えます。
*   **具体例:** Backlog（バックログ）、Asana、Notion、Jira など。

### 3. 「プログラミングスクール」「AI学習」
*   **狙い:** 「AIツールを使いこなすためのスキル」として紹介します。学習系の商材は1件成約で1万円〜3万円を超える超高単価が魅力です。
*   **具体例:** テックキャンプ、SAMURAI ENGINEER、Aidemy（AI特化スクール）など。

### 4. 「会計ソフト」「バックオフィス自動化」
*   **狙い:** 個人事業主やフリーランスの事務作業を自動化する文脈で売れます。
*   **具体例:** freee（フリー）、マネーフォワード、弥生会計など。

### 5. 「ビジネスマッチング」「フリーランスエージェント」
*   **狙い:** 「AIでスキルを身につけた後の稼ぎ方」として誘導します。登録系の案件はハードルが低く、成約しやすいです。
*   **具体例:** クラウドワークス、ランサーズ、レバテックフリーランスなど。
